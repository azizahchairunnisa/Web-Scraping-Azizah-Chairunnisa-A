# Web Scraping Berita CNN Indonesia

Proyek sederhana menggunakan Python untuk melakukan *web scraping* pada portal berita CNN Indonesia guna mengambil judul dan isi berita, lalu menyimpannya ke dalam format CSV dan Excel.

## 🛠️ Library yang Digunakan
* `requests` - Untuk mengambil halaman web.
* `beautifulsoup4` - Untuk mem-parsing elemen HTML.
* `pandas` - Untuk merapikan data ke dalam bentuk tabel dan menyimpannya ke file.

## 🚀 Cara Menjalankan Program
1. Pastikan Anda sudah menginstal library yang dibutuhkan:
   ```bash
   pip install requests beautifulsoup4 pandas openpyxl
